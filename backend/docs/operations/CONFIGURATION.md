# Configuration

Required production variables:

- `SPRING_DATASOURCE_URL`
- `SPRING_DATASOURCE_USERNAME`
- `SPRING_DATASOURCE_PASSWORD`
- `APP_JWT_SECRET`
- `APP_CORS_ALLOWED_ORIGINS`
- `APP_BOOTSTRAP_ADMIN_ENABLED`
- `APP_STORAGE_ENABLED`
- `APP_STORAGE_ENDPOINT`
- `APP_STORAGE_REGION`
- `APP_STORAGE_BUCKET`
- `APP_STORAGE_ACCESS_KEY`
- `APP_STORAGE_SECRET_KEY`
- `APP_DASHBOARD_BUSINESS_TIME_ZONE`

Required when Telegram is enabled:

- `APP_TELEGRAM_ENABLED=true`
- `APP_TELEGRAM_BOT_TOKEN`
- `APP_TELEGRAM_WEBHOOK_SECRET`
- `APP_TELEGRAM_BOT_USERNAME`

Important operational variables:

- `APP_AUTH_THROTTLE_MAX_FAILURES`
- `APP_AUTH_THROTTLE_WINDOW`
- `APP_AUTH_THROTTLE_BLOCK_DURATION`
- `APP_NOTIFICATION_BATCH_SIZE`
- `APP_NOTIFICATION_POLL_INTERVAL`
- `APP_NOTIFICATION_PROCESSING_LEASE`
- `APP_CLEANUP_ENABLED`
- `APP_CLEANUP_BATCH_SIZE`
- `APP_DB_POOL_MAX_SIZE`
- `APP_SHUTDOWN_TIMEOUT`

Production validation fails startup with `PRODUCTION_CONFIGURATION_INVALID` when required values are missing or unsafe. Validation messages are sanitized and do not print secret values.
